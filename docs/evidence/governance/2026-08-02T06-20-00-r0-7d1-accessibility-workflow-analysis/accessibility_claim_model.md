# Accessibility claim model

## Allowed (only with evidence)

- `ACCESSIBILITY_WORKFLOW_EXECUTES`
- `STATIC_ACCESSIBILITY_CHECKS_PASS`
- `DESIGN_TOKEN_CONTRAST_CHECKS_PASS`
- `BROWSER_AXE_CHECKS_PASS`
- `ACCESSIBILITY_REPORT_PUBLISHED`
- `AUTOMATED_WCAG_RULESET_PASS` (named ruleset only)

## Prohibited

- Full WCAG conformity
- Legal accessibility compliance
- Usability for all assistive technologies
- Manual-review completion
- Production accessibility readiness

# NP1D Authorization Boundary

Authorized:

- modify exactly the seven existing R0-7E normative governance paths;
- create one new correction evidence package;
- create one normative-correction commit;
- create one evidence-only commit;
- perform one normal non-force push.

Not authorized:

- amendment, rebase, reset, rewrite, deletion, or force-push;
- workflows, source, manifests, lockfiles, database reconstruction, R0-7D or
  R0-7E implementation;
- pull-request creation, merge, deployment, or representation of author
  self-review as independent review.

`DRAFT_PR_AUTHORIZATION = false`
`IMPLEMENTATION_AUTHORIZATION = false`
`MERGE_AUTHORIZATION = false`
`DEPLOYMENT_AUTHORIZATION = false`

# Acceptance Criteria

The P1 package passes only when all are true:

- integration identity and PR #8 merge identity are exact;
- exactly one new evidence folder is changed;
- no existing file, application code, package source, or workflow changes;
- scope and all four CI lanes are explicit;
- R0-7D is implementation-blocking;
- database disposition remains an owner decision;
- policy and implementation compliance are distinct;
- F4 is a separate focused prerequisite;
- the missing technical-debt register is recorded without creating it;
- immutable action and artifact pinning is proposed;
- work packages and owner gates are separate and bounded;
- non-claims and stop conditions are explicit;
- summary.json parses and changed-file inventory matches Git;
- one planning-only commit has the expected parent and subject;
- local and remote planning tips match after a normal non-force push;
- integration remains unchanged, repository is clean, and deployment is zero.

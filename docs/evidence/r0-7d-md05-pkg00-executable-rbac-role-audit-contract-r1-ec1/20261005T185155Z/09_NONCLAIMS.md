# 09 — Non-claims

EC1 does not:

- declare the original candidate a PASS;
- rewrite the independent review or its FAIL/REJECT result;
- rewrite or replace the original evidence directory;
- claim the original `e677aa7c...` ZIP is valid or available;
- describe the delivered `f54f7395...` recovery package as that original container;
- repair `DELIVERED_CONTENT_MATCHED_ORIGINAL_COMMITTED_EVIDENCE = false`;
- resolve MD05;
- authorize implementation beyond PKG-00;
- add a role-management endpoint;
- add identity-provider administration;
- add database role persistence;
- implement complaints or appeals;
- emit an audit row;
- mutate `roles.ts`, `auth.ts`, the MFA specs, or `index.ts`;
- create a pull request;
- merge;
- deploy.
